Lost & Found Game Plan

We build a website for mall security. A guard types "Lost boy, about 6, red t-shirt" and the website answers three questions using the mall's camera recordings:

1 · Where did the family go?

Their path from camera to camera on the mall map.

2 · Where did they lose him?

The exact clip and second the boy walked away.

3 · Where is he now?

The last camera that saw him, so a guard can go there.

Why we make our own footage

Real recordings of a lost child across mall cameras are never published (privacy). Public datasets don't have this story. So we generate 8 short clips with Kling that look like recordings from the mall's security cameras. Then the system searches them exactly as it would search real recordings.

The story timeline

Each row is a security camera in the mall. Time runs left to right from 14:00 to 14:35. A real mall records every camera all day; we only make the 8 pieces of 15 seconds where something important happens (the coloured boxes). Click a box to jump to its prompt.

Family together, or parents The separation moment The boy alone Report and reunion

Read the boxes in time order and you have the story: the family enters (1), shops together (2), loses the boy in the electronics store (3). He wanders across the atrium (4) and ends up lost at the food court (5). The parents search the wrong side (6), report to security (7), and are reunited with him (8).

The 8 clips to generate

Kling 3.0 on Higgsfield, 16:9, 15 seconds (10 s is fine if it's cheaper), no audio needed. 8 clips ≈ $7.56, which leaves about $7 to redo bad ones. Every prompt below already includes the camera style and the three characters, so just press Copy.

Who does what

You

  • Make 3 character pictures (father, mother, boy) on Higgsfield's image tool. Prompts are in Step 1 below.
  • Generate the 8 clips with the prompts above. Use the character pictures as the start or reference image when the tool allows it.
  • Name the files 01.mp4 … 08.mp4 and upload them to the repo folder demo/raw/ (or send me a Drive link).
  • Get a CreativAI API key and add it to this environment as a secret named CREATIVAI_API_KEY. Don't paste it in chat.

Me (Claude)

  • Add the camera name and clock to every clip so they look like real recordings.
  • Upload them to CreativAI and test the searches.
  • Write the Map code (which camera is next to which, and walking times).
  • Build the website: guard types the report → path on the map → separation clip → "boy is here now".
